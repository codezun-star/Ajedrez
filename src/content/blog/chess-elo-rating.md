# チェスのEloレーティング：意味・計算方法・上げ方

Eloレーティングは、あなたの実力をひとつの数字にまとめたものです。何局勝ったかではな
く、**誰に勝ったか** を測ります。自分より400点上の相手に勝てば価値は非常に大きく、
400点下の相手に勝ってもほとんど価値はありません。

この記事では、その数字がどこから来るのか、あなたの数字が何を意味するのか、そして実
際に何がそれを押し上げるのかを説明します。

## Eloシステムとは

考案したのはハンガリー系アメリカ人の物理学者 **アルパド・エロ**。FIDEが1970年に採用
しました。仕組みは単純です。各プレイヤーがレーティングを持ち、二人のレーティング差
が対局の **期待結果を予測** します。

システムの予測を上回れば上がり、下回れば下がる。それだけです。

## 実際の計算方法

手順は二つ。

### ステップ1：期待勝率

あなたの勝つ確率は次の式で求めます。`Ra` があなたのレーティング、`Rb` が相手のレー
ティングです。

```
E = 1 / (1 + 10^((Rb - Ra) / 400))
```

**400** という数字がこのシステムの核心です。400点差は、格上が **11局中およそ10局**
勝つはずだ、という意味になります。

いくつか例を挙げます。

| レーティング差 | 格上の期待勝率 |
| --- | --- |
| 0点 | 50% |
| 100点 | 64% |
| 200点 | 76% |
| 400点 | 91% |

### ステップ2：調整

```
新レーティング = 現在のレーティング + K ×（実際の結果 − 期待勝率）
```

**実際の結果** は勝ちが1、引き分けが0.5、負けが0です。

**K値** は1局あたりの変動幅を決めます。FIDEでは：

- **K = 40**：新規プレイヤー（30局未満）。
- **K = 20**：大多数のプレイヤー。
- **K = 10**：2400以上。

最初のうちレーティングが大きく揺れるのはこのためです。システムはまだあなたの本当の
実力を知らないので、素早く動いてそれを探ろうとします。

### 計算例

あなたが1200で、1400の相手に勝ったとします。期待勝率は
`1 / (1 + 10^(200/400)) = 0.24`。K = 40 なら：

```
1200 + 40 ×（1 − 0.24）= 1200 + 30.4 ≈ 1230
```

30点の上昇です。同じ対局に負けていたら下がるのは10点ほど。格上に負けることは織り込
み済みだからです。

## 自分の数字が示すもの

以下の区分は目安ですが、位置を把握するには十分です。

| Elo | 実力 |
| --- | --- |
| 1200未満 | 初心者：ルールは分かるが、まだ駒をただで取られる |
| 1200 – 1400 | 入門者：1手の戦術は見える |
| 1400 – 1600 | 中級者：計画を立て、2〜3手読める |
| 1600 – 1800 | 強いクラブ級：大きな戦術ミスは少ない |
| 1800 – 2000 | 上級者：終盤の技術が確か |
| 2000 – 2200 | エキスパート／候補マスター |
| 2200 – 2400 | FIDEマスター、インターナショナルマスターの領域 |
| 2500以上 | グランドマスター |

**サイトをまたいだ比較には注意してください。** あるサイトのEloはFIDEのEloではありま
せん。プラットフォームごとに参加者層も定数も違います。システム間で200〜300点の差が出
るのはごく普通のことです。

## レーティングを本当に上げる5つのこと

### 1. 駒をただで取られるのをやめる

1600以下では、対局の大半は駒を無償で渡してしまうことで負けています。一手指す前に二
つの質問を。**相手は何を狙っているか？** そして **自分のどの駒が無防備か？**

### 2. 毎日戦術を解く

1日15分が、日曜の3時間に勝ります。パターンは反復で定着するのであって、強度では定着
しません。

### 3. 終盤を4つ覚える

キング＋クイーン対キング、キング＋ルーク対キング、キング＋ポーン対キング、そしてルー
ク終盤。優位を勝ちに変える場面こそ、純粋な技術不足で最も多くの点がこぼれるところで
す。

### 4. 持ち時間の長い対局を指す

早指しでは、すでに知っていることを繰り返すだけです。時間があれば読み、間違え、その
理由に気づけます。上達はそこから生まれます。

### 5. 負けた対局を見直す

**PGN** を書き出し、形勢が傾いた正確な一手を探しましょう。エンジンが必要になること
はまれで、たいていは自分で見つかります。

## 数字にとらわれないために

Eloは体温計であって、目標ではありません。強くなれば上がるものであり、点を減らさない
ために指すと、複雑な局面を避けるようになります——学べるのは、まさにその複雑な局面な
のに。

勝率が **5割前後** になる難易度を選んでください。そこがいちばん伸びます。いつも勝つ
相手からは何も学べませんし、いつも自分が勝つ相手からも同じです。

## よくある質問

### チェスのレーティングはどれくらいあれば良いですか？
文脈によります。1200を超えれば基礎は身についており、1600は堅実なクラブプレイヤー、2000はエキスパート級です。公式戦の登録者の平均は1600前後ですが、オンラインの平均はそれより低い傾向があります。

### Eloは正確にはどう計算しますか？
二段階です。まず期待勝率 `E = 1 / (1 + 10^((Rb − Ra)/400))`、次に調整 `新レーティング = レーティング + K ×（実際 − 期待）`。Kは新規プレイヤーが40、大多数が20、2400以上は10です。

### 格下に勝ったとき、なぜ点がほとんど増えないのですか？
システムがもともとあなたの勝ちを見込んでいたからです。期待勝率が0.9で勝った場合、得られるのは K × 0.1 だけ。裏を返せば、その対局に負けたときの失点は非常に大きくなります。

### サイトのEloはFIDEのレーティングと同じですか？
違います。各プラットフォームは独自の参加者層と定数で自前のEloを算出しているため、数字を直接比べることはできません。システム間で200〜300点ずれるのは普通です。

### 1年でどれくらい上がりますか？
継続して練習すれば、初心者が数か月で数百点伸ばすことは珍しくありません。上に行くほど伸びは鈍ります。1200から1500へ上がるほうが、1900から2000へ上がるよりずっと速いのです。
