# 快速将死：牧师杀和另外 6 种杀法

1500 等级分以下的对局，几乎都终结于半打左右的固定杀法。它们不是什么天才组合，而
是反复出现的图形——只要见过一次，下次一眼就能认出来。本文讲最常见的七种：怎么下
出来，以及更重要的，**怎么防止别人对你下出来**。

## 将死到底是什么

将死，就是王被攻击且没有任何合法的解法。应将只有三种办法：移动王、吃掉将军的棋
子、或者在中间垫子。三者都不存在时，棋局立刻结束。

注意最常见的混淆：如果你无子可动但 **没有** 被将军，那是 **逼和**，算和棋，不是
输棋。

## 1. 牧师杀（四步）

最有名的杀法，也是新手对局中决定胜负最多的一种。

```
1. e4 e5
2. Bc4 Nc6
3. Qh5 Nf6??
4. Qxf7#
```

思路是：后和象同时瞄准 **f7**——黑方最薄弱的格子，因为只有王在守。第四步后吃掉
f7，且受到 c4 象的保护，王既吃不掉也逃不了。

### 如何防守

关键是别走 `3...Nf6??`。两种稳健的防守：

- **3...g6**，攻击后。接着 `4.Qf3` 时再走 `4...Nf6`，局面就很好：马是在把后赶走
  *之后* 才到 f6 的。
- **3...Qe7**，用后来守 f7。

这条通用原则适用于整个开局：**如果对手把两个子对准 f7（你执白时则是 f2），先数清
攻击方和防守方，再继续自己的计划。**

## 2. 愚人杀（两步）

国际象棋中最快的杀法，倒霉的是白方：

```
1. f3 e5
2. g4 Qh4#
```

走动 f 兵和 g 兵，把 e1–h4 这条斜线彻底敞开，直通王位。实战中你几乎见不到它，但
它道出了开局最重要的一课：**你在王前推的每一个兵，都是打开的一扇门**。

## 3. 底线杀

实战中最常见的一种。王已易位，身前三个兵都没动过，而一个车或后落到了底线：

- 王在 g1，兵在 f2、g2、h2。
- 黑车走到 e1 或 d1 → 将死，因为王没有任何逃格。

### 如何避免

给王开个 **气孔**：在局面平稳时推一步边兵（白方 h3，黑方 h6）。仅仅一步兵，就能
消除这一整类杀法。另外，在兑车之前，永远先确认自己的底线不会失守。

## 4. 闷杀

马将死一个被 **自己人** 堵死的王。经典手顺，被称为 *菲利多的遗产*：

```
1. Qb3+ Kh8
2. Nf7+ Kg8
3. Nh6++ Kh8
4. Qg8+! Rxg8
5. Nf7#
```

g8 处的弃后是全局的妙笔：它逼迫车去占据王最后一个空格。这是本文最漂亮的图形，而
且只要对方的王被自己人围住，它出现的频率比想象中高。

## 5. 阿拉伯杀（车马配合）

已知最古老的杀法之一。马在 f6，车在 h7，黑王在 h8：马控制 g8 和 h7，车完成将杀。
对付角落里的王，车马是一对致命组合。

## 6. 天梯杀（双车）

你应该不假思索就能下出来的基本杀法。用两个车（或车加后）交替封锁横线：

- 一车走到第 7 横线 → 王被迫上到第 8 横线。
- 另一车落到第 8 横线 → 将死。

正是这门技术，把任何巨大优势兑现为胜利。

## 7. 阿纳斯塔西娅杀

马在 e7，车沿 h 线压下，黑王在 h7、兵在 g7。马控制 g8 和 g6，车在 h 线上收官。当
对手推了 h 兵、而你又有一匹活跃的马时，这个图形非常常见。

## 速查表

| 杀法 | 用子 | 出现时机 |
| --- | --- | --- |
| 牧师杀 | 后 + 象 | e4 开局，对付新手 |
| 愚人杀 | 后 | 仅当对手连走 f 和 g |
| 底线杀 | 车或后 | 中残局，王没有气孔 |
| 闷杀 | 马 + 后 | 王被自己的子围死 |

## 真正有效的训练方法

识别图形靠的是视觉记忆，不是计算。三个管用的习惯：

1. **每走一步前，先看对手的底线。** 有没有气孔？没有的话，想办法把车插进去。
2. **整个开局都数着 f7 / f2 的攻防子数。**
3. **在「简单」难度和 AI 对局，强迫自己用某个指定图形收官。** 靠子力取胜很容易；
   逼自己去找杀，才是练眼力。

当这七种图形能自动浮现时，大部分速败就与你无关了。开一盘棋，专门去猎取底线杀——
那是你最常遇到的一种。

## 常见问题

### 国际象棋最快的将死是哪一种？
愚人杀，两步：1.f3 e5 2.g4 Qh4#。它只有在白方前两步同时推 f 兵和 g 兵时才成立，所以实战中几乎不会出现。

### 怎么防守牧师杀？
最简单的是走 3...g6 攻击后，之后再把马跳到 f6。3...Qe7 同样能守住 f7。会输棋的一手是 3...Nf6，因为这样 f7 就只剩王在守。

### 将死和逼和有什么区别？
将死时你的王被攻击且没有合法着法，判负。逼和时你没有被将军，但同样没有合法着法，棋局以和棋结束。

### 怎样避免底线杀？
在局面平稳时推一步边兵（白方 h3，黑方 h6），给王留一个逃格。另外在兑车之前，先检查自己的底线是否会失去保护。

### 只用王和马能将死对方吗？
不能。王加马对单王属于子力不足，判和。王加象同样不够。要强制将死，最少需要王加车、王加后，或者双象。
