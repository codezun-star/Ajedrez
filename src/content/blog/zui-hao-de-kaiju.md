# 新手最值得学的 7 个国际象棋开局

你不需要二十个开局。你需要的是 **执白一个，外加应对对手每种首着各一个**——而且理
解到第 10 步时清楚自己想干什么。下面这七个正好覆盖这些需求，按难度排列，每个都附
上作战计划，而不只是着法顺序。

## 怎么挑自己的开局

在看清单之前，先回答真正要紧的问题：**你想下什么样的局面？**

| 如果你喜欢…… | 就下…… |
| --- | --- |
| 快速进攻、子力活跃 | 意大利、西西里 |
| 稳健清晰的局面 | 西班牙、后翼弃兵 |
| 封闭结构与长线计划 | 法兰西、伦敦体系 |
| 一套走法反复使用 | 伦敦体系 |

一条能省下好几个月的建议：**挑一个，然后下五十盘。** 每盘都换开局，是学不会任何
开局的最快方式。

## 1. 意大利开局（白方）

```
1. e4 e5
2. Nf3 Nc6
3. Bc4
```

现存最好的入门开局。它一字不差地贯彻三条原则：兵占中心、马出动、象走到瞄准 f7 的
活跃斜线上。

**计划：** 尽快易位，走 c3 和 d4 建立强大中心，再把子力调向对方王翼。你在这里学到
的一切，几乎能搬到任何别的开局里去。

## 2. 西班牙开局 / 鲁伊·洛佩兹（白方）

```
1. e4 e5
2. Nf3 Nc6
3. Bb5
```

高水平棋史上使用最多的开局。象施压于那只防守 e5 的马。

**计划：** 目标不是赢兵（3...a6 4.Bxc6 dxc6 会把子力还回去），而是积累一点长期的
位置优势。它比意大利开局更深——等意大利下顺手了再转过来。

## 3. 西西里防御（黑方应 1.e4）

```
1. e4 c5
```

面对 1.e4 最流行、也最具战斗性的应法。黑方不用 1...e5 去镜像白方，而是从侧翼冲击
中心。

**计划：** 用 c 兵换掉白方 d 兵，保有半开放的 c 线，在后翼展开反击。它锋利且理论
量大，所以先从 **封闭西西里** 这类简单版本入手，不必去背二十步的纳道尔夫。

## 4. 法兰西防御（黑方应 1.e4）

```
1. e4 e6
2. d4 d5
```

稳健且结构感极强。黑方搭起兵链，接受一个略显笨拙的白格象，换来一个很难攻破的局
面。

**计划：** 用 ...c5 冲击中心，向 d4 兵施压。如果你喜欢先防守再反击，法兰西就是你
的开局。

## 5. 卡罗-卡恩防御（黑方应 1.e4）

```
1. e4 c6
2. d4 d5
```

与法兰西相似，却没有它的主要毛病：这里白格象在 ...e6 封住兵链之前就先出去了。

**计划：** 舒展的出子、健康的兵形，以及略优的残局。这是给那些不愿在前十五步冒险的
棋手准备的开局。

## 6. 后翼弃兵（白方）

```
1. d4 d5
2. c4
```

虽然叫弃兵，其实并非真正的弃兵：黑方若以 2...dxc4 吃下，白方能轻松把兵追回来。

**计划：** 献出 c 兵引开黑方 d 兵，从而保有压倒性的中心。要理解「用兵控制中心」到
底是什么意思，没有比它更好的开局了。

## 7. 伦敦体系（白方）

```
1. d4 d5
2. Bf4
```

诚实的捷径。它是一套 **体系**：无论对手怎么下，你几乎都走同一套阵型——d4、Bf4、
e3、Bd3、Nf3、c3、Nbd2。

**计划：** 安全而自动的出子，短易位，然后在王翼展开平稳的进攻。如果你不想啃理论，
宁愿把时间花在战术上，这就是你的体系。

## 三行写完的完整开局库

如果你只想要「不再临场瞎下」的最低配置：

- **执白：** 意大利开局（偏好 1.d4 的话就用伦敦体系）。
- **应 1.e4：** 卡罗-卡恩。
- **应 1.d4：** 1...d5，正常出子。

就这些。靠这三样，面对 1800 分以下几乎任何对手，你都能从容走到第 12 步。

## 会毁掉任何开局的错误

背着法却不理解计划。一旦对手离开「你的变例」——而他第 4 步就会离开——你立刻无计可
施。

反过来做：开局的每一步都问自己 **这一手是在出子、在控制中心，还是在让王更安全？**
如果答案都不是，那多半存在更好的一手。

现在就挑这七个中的一个和 AI 对局，连下五盘再换。把清单变成开局库的，正是重复。

## 常见问题

### 新手最适合学哪个国际象棋开局？
意大利开局（1.e4 e5 2.Nf3 Nc6 3.Bc4）。它直接落实了三条开局原则——中心、出子、易位，而且在其中学到的思路几乎能用到所有其他开局上。

### 我应该学几个开局？
1800 分以下三个就够：执白一个、应 1.e4 一个、应 1.d4 一个。把三个真正下懂，远胜过认得十个的名字。

### 西西里防御适合新手吗？
它是应对 1.e4 最具战斗性的下法，局面非常丰富，但理论量也最大。刚起步的话，选封闭西西里这类简单版本，或者先下卡罗-卡恩，等一般原则掌握牢了再说。

### 伦敦体系是什么，为什么这么流行？
它是由 d4、Bf4、e3、Bd3、Nf3、c3、Nbd2 组成的出子阵型，几乎可以对任何应法重复使用。流行是因为几乎不需要背谱，能把时间省下来练战术。

### 一定要背开局着法吗？
不必。你需要理解的是计划：想控制哪些格子、子力该摆在哪里。没有计划的死记，一旦对手变着就会崩塌——而这几乎总会发生，而且很早就发生。
