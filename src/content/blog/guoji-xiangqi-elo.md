# 国际象棋等级分（Elo）：是什么、怎么算、怎么涨

等级分是用一个数字概括你棋力的东西。它衡量的不是你赢了多少盘，而是 **你赢的是
谁**。战胜比你高 400 分的人价值极大；战胜比你低 400 分的人，几乎不值什么。

这篇文章讲清楚这个数字从哪来、你的分数意味着什么，以及什么才真正让它上涨。

## Elo 系统是什么

它由匈牙利裔美国物理学家 **阿尔帕德·埃洛（Arpad Elo）** 提出，国际棋联在 1970 年正
式采用。思路很简单：每位棋手有一个分数，两个分数之间的差距 **预测这盘棋的期望结
果**。

赢得比系统预测的多，分数就涨；比预测的少，分数就跌。就这么回事。

## 实际怎么计算

分两步。

### 第一步：期望得分

你的胜率按下式计算，其中 `Ra` 是你的分数，`Rb` 是对手的分数：

```
E = 1 / (1 + 10^((Rb - Ra) / 400))
```

**400** 这个数字是整个系统的核心：相差 400 分意味着高分方大约应该 **11 盘赢 10
盘**。

几个例子：

| 分差 | 高分方期望得分 |
| --- | --- |
| 0 分 | 50% |
| 100 分 | 64% |
| 200 分 | 76% |
| 400 分 | 91% |

### 第二步：调整

```
新分数 = 当前分数 + K × (实际得分 − 期望得分)
```

**实际得分** 胜为 1，和为 0.5，负为 0。

**K 值** 决定每盘棋分数波动多大。国际棋联的规定：

- **K = 40**：新棋手（不足 30 盘）。
- **K = 20**：大多数棋手。
- **K = 10**：2400 分以上。

这就是为什么刚开始分数起伏很大：系统还不知道你的真实水平，所以移动得快，好尽快找
到它。

### 一个完整算例

你 1200 分，战胜了一位 1400 分的对手。你的期望得分是
`1 / (1 + 10^(200/400)) = 0.24`。取 K = 40：

```
1200 + 40 × (1 − 0.24) = 1200 + 30.4 ≈ 1230
```

你涨了 30 分。同样这盘棋如果输了，只会掉大约 10 分——输给更强的人本就在预料之中。

## 你的分数代表什么

以下分段是大致参考，但足以给你定位：

| Elo | 水平 |
| --- | --- |
| 1200 以下 | 新手：规则会了，还常常送子 |
| 1200 – 1400 | 入门：能看出一步的战术 |
| 1400 – 1600 | 中级：会做计划，能算两三步 |
| 1600 – 1800 | 较强的俱乐部棋手：严重战术失误不多 |
| 1800 – 2000 | 高级：残局技术扎实 |
| 2000 – 2200 | 专家 / 候补大师 |
| 2200 – 2400 | 国际棋联大师与国际大师区间 |
| 2500 以上 | 特级大师 |

**跨网站比较分数要小心。** 某个网站的 Elo 不等于国际棋联的 Elo：每个平台有自己的棋
手群体和自己的常数。两套系统之间相差 200 到 300 分是完全正常的。

## 真正能让你涨分的 5 件事

### 1. 别再送子

1600 分以下，大多数棋是靠白送子力输掉的。每走一步前问两个问题：**对手在威胁什
么？** 以及 **我有哪些子没有保护？**

### 2. 每天练战术

每天十五分钟，胜过周日一次三小时。图形是靠重复扎根的，不是靠强度。

### 3. 学会四种残局

王后对单王、王车对单王、王兵对单王，以及车兵残局。把优势兑现成胜利，正是纯技术上
丢分最多的环节。

### 4. 下慢棋

快棋只是重复你已经会的东西。时间充裕时你才会算、才会算错，然后弄明白为什么。进步
就是从这里来的。

### 5. 复盘你的败局

导出 **PGN**，找出局面翻转的那一步。通常不需要引擎——多数时候你自己就能看出来。

## 关于「盯着分数」的一点建议

Elo 是温度计，不是目标。它会在你棋力提高时上涨；而为了不掉分去下棋，会让你回避复杂
局面——偏偏那正是长棋的地方。

挑一个你大约能赢 **一半** 的难度。那里学得最快：总是赢你的对手教不了你什么，总是被
你赢的对手同样教不了。

## 常见问题

### 国际象棋多少等级分算好？
要看语境。1200 分以上说明基础已经过关，1600 分是扎实的俱乐部棋手，2000 分属于专家水平。注册棋手的平均分大致在 1600 左右，不过在线平台的平均分通常更低。

### Elo 到底是怎么算的？
两步：先算期望得分 `E = 1 / (1 + 10^((Rb − Ra)/400))`，再做调整 `新分数 = 分数 + K × (实际 − 期望)`。K 值对新棋手为 40，大多数棋手为 20，2400 分以上为 10。

### 为什么赢下比我弱的对手涨分那么少？
因为系统本来就预期你会赢。如果期望得分是 0.9 而你赢了，只能拿到 K × 0.1。反过来说，这盘棋一旦输掉，代价会非常大。

### 网站上的 Elo 和国际棋联的等级分一样吗？
不一样。每个平台用自己的棋手群体和常数计算自己的 Elo，所以数字不能直接对比。两套系统相差 200 到 300 分是很正常的。

### 一年能涨多少分？
只要坚持练习，新手在几个月内涨几百分是常见的。分数越高进步越慢：从 1200 涨到 1500，比从 1900 涨到 2000 要快得多。
